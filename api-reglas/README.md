# api-reglas

Small FastAPI service with the validation rules of Aula Norte, so any system (n8n, a website, a script) can reuse them.

## Routes

| Method | Path | What it does |
|---|---|---|
| GET | `/cursos` | Returns the list of courses. |
| POST | `/validar-interesado` | Receives a JSON and returns which required fields (`nombre`, `email`, `curso`) are missing or empty: `{"ok": false, "faltan": ["email"]}`. |
| GET | `/docs` | Interactive documentation generated by FastAPI. |

## Run it in 3 commands

Requires Docker.

```bash
cd api-reglas
docker build -t api-reglas .
docker run -p 8000:8000 api-reglas
```

Then open `http://localhost:8000/docs`.

## Example

```bash
curl -X POST http://localhost:8000/validar-interesado \
  -H "Content-Type: application/json" \
  -d '{"nombre": "Ana", "email": "   ", "curso": "Excel"}'
```

Response:

```json
{"ok": false, "faltan": ["email"]}
```

A field with only spaces counts as missing.
